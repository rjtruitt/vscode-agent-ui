# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release
- Core components: Button, Card, Badge, Progress, Input, Select, Toggle, Table, Tabs
- Chat components: ChatBubble, ChatInput
- Layout components: Panel
- Additional components: Accordion, Box, Canvas, DiffViewer, MetricCard, StatBox, Terminal, ToolCard
- Theme-aware styling with VS Code variables
- State preservation for inputs, tabs, and accordions
- Accessibility features (ARIA labels, keyboard navigation)
- CSP-compliant inline styles
- TypeScript type definitions
